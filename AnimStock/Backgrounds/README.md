# Fonds d'écran

Déposer ici les images de fond du jeu, au format PNG ou JPG.

| Fichier attendu | Où il s'affiche |
|---|---|
| `Background_Menu.png` | derrière le tableau de bord (Jouer / Système / …) |
| `Background_Board.png` | derrière le plateau, pendant la partie |

Tant qu'un fichier est absent, l'écran retombe sur son dégradé : rien ne
casse, le fond est simplement uni.

Comme tout le reste d'`AnimStock/`, ces images viennent du repo
`LudoPolyAnimation` et sont recopiées ici :

```bash
cp -R ~/Desktop/LudoPolyAnimation/AnimStock/ ~/Desktop/LudoPoly/AnimStock/
```
